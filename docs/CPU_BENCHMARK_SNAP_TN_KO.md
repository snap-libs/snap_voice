# CPU Benchmark for SNAP TN (Text Normalization & Phonology Engine)

> **[안내: CPU 단독 연산 측정]**  
> 본 벤치마크는 GPU를 사용하지 않고(0.00% 개입), CPU 단독 환경(Pure CPU Native)에서 측정한 결과입니다.

- **문서 버전**: v1.3.0
- **측정 일시**: 2026-09-30
- **테스트 엔진**: SNAP C++ Native Engine v2.3.0
- **런타임 환경**: C++17 Native, Linux x86_64, ONNX Runtime 1.18.1 CPU Execution Provider

---

## 1. 벤치마크 개요

본 문서는 SNAP(Semantic Normalization via Attached Probes) C++ 네이티브 텍스트 정규화(TN) 및 음운 변환 엔진의 CPU 하드웨어별 실측 성능 데이터를 제공합니다.

서로 다른 클럭, 캐시 구조, 벡터 연산 유닛을 가진 CPU 4종을 대상으로 동일한 C++ 네이티브 벤치마크를 수행하여 하드웨어 특성에 따른 성능 차이를 실측하였습니다.

## 4. 벤치마크 리뷰

실측 결과, 테스트된 모든 CPU 환경에서 실시간 텍스트 정규화 처리에 충분한 성능을 보였습니다. 하드웨어 세부 특성에 따른 관찰 결과는 다음과 같습니다.

* **L3 캐시**: SNAP 엔진의 런타임 메모리 사용량은 **약 100 ~ 130 MB**입니다. 코어가 접근 가능한 L3 캐시가 이 워킹셋을 수용할수록 DRAM 접근이 줄어들어 P99 지연시간이 안정화되는 경향을 보였습니다.
* **벡터 연산 유닛**: 신경망 행렬 연산 비중이 높아, 512-bit 벡터 명령어(AVX-512) 및 8비트 정수 연산(VNNI)을 지원하는 프로세서에서 배치 처리량이 증가하는 결과가 나타났습니다.
* **클럭 속도**: 단일 문장 처리 지연시간은 전체 코어 수보다 단일 코어의 클럭 속도에 직접적인 영향을 받는 것으로 확인되었습니다.
